# Build Status

## Design Standards

- **Blueprint Visual Experience Directive** — ✅ Established
  (2026-08-10). See [`BLUEPRINT_MASTER_SPEC.md`](./BLUEPRINT_MASTER_SPEC.md).
  This directive defines the mandatory premium visual design standard
  (brand color system, visual hierarchy, quiz/results/dashboard/roadmap
  component specs, typography, accessibility, and the pre-completion
  visual quality checklist) for the entire Blueprint platform. It applies
  to all future phases — including the assessment, results screens,
  dashboard, roadmap, Business Builder, and My Blueprint — and no screen
  in those phases should be marked complete unless it meets this standard.
